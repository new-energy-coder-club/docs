## 使用说明

**浏览与探索**

- **拖拽节点**：移动后松手自动固定位置（节点右上角出现小钉子标记），右键节点取消固定
- **双击节点**：进入「邻居聚焦」模式——只显示该页面 N 跳内的互链子图，顶部面包屑可切换 1~3 跳深度、直达文档或退出
- **单击节点**：在新标签页打开对应文档页
- **悬停节点**：显示标题、板块、互链数，高亮相邻节点与连线
- **搜索框**：输入标题关键字（支持下拉候选），回车定位并放大到该页面

**分析工具（顶部工具栏）**

- **⛶ 全屏**：嵌入状态下也能把整个图谱铺满屏幕，`Esc` 或再点一次退出；若浏览器拦截 iframe 全屏，自动退化为新标签页打开独立图谱页
- **⇄ 路径**：任选两个页面，BFS 查找最短互链路径并以橙色高亮整条链路——适合回答「从新人指南到某篇电机手册要经过哪些页面」
- **◎ 孤岛**：一键红色高亮没有任何互链的页面，方便维护者发现断档内容
- **⟲ 重置**：退出聚焦、清除路径/孤岛高亮、恢复全部板块并复位视图
- `Esc` 快捷键：退出聚焦 / 清除路径高亮 / 退出全屏；左下角图例与顶部下拉可按板块筛选

## 数据来源与更新

图谱数据由脚本离线生成，**不需要任何后端服务**：

```bash
python tools/kg/build_graph.py
```

脚本读取 `docs.json` 导航中注册的所有页面，解析 Markdown 链接与 MDX `href` 中的站内跳转，输出 `kg/graph-data.js`（`window.NEC_GRAPH` 全局变量，force-graph 兼容格式）。页面结构变化后重新运行即可，图谱页会自动加载最新数据。
