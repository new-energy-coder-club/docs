## 1. 工种概述

### 1.1 职责定位

电控组在 NEC ROBOCON 战队中负责：

- **电机选型与验证**：所有电机的选型确认、最低成本方案评估、赞助电机测试任务（朱佩韦：「电控这里要把选型和验证所有电机的相关确认完」，[26NEC RC 电控总群 2025-10-29]）。
- **驱动板与底层控制**：电机驱动、遥控器、电调的选型、焊接、调试（单广志：「电机驱动，遥控都需花大量时间」，[26NEC RC 电控总群 2025-11-03]）。
- **整车功率与电池配电**：总功率核算、负载电压/电流/C 数计算、18650 电池组装配（点焊机+镍带+青稞绝缘纸）（[26NEC RC 电控总群 2025-12-01]）。
- **嵌入式下位机开发**：基于 STM32 / ESP32 / 大疆 A 板 C 板等控制器，跑 FreeRTOS / PlatformIO / Arduino / MicroPython 等框架。
- **跨组接口**：与机构组对接电机安装、与视觉组对接上位机（K230、Orange Pi、树莓派）、与运营对接赞助测试交付物（开箱视频、测试视频）。

### 1.2 技术栈

语料中实际出现的技术栈：

- **主控 MCU**：STM32 F407（F407_can.rar 例程）、ESP32、ESP8266。
- **开发板**：大疆 RoboMaster 开发板 A 型 / C 型、重邮 A 板（舵狗使用）、达妙 DM-MC02、Orange Pi 3B（Rockchip，跑 Ubuntu 22.04）。
- **嵌入式框架**：HAL 库 + CubeMX（STM32）、PlatformIO、ESP-IDF、Arduino、MicroPython（uPyCraft 烧录）。
- **总线/协议**：CAN（USB 转 CAN 分析仪、达妙双路 CAN 调试仪）、RS485（宇树 485 转 USB + 485 转 CAN 模块转接）、UART、SBUS（遥控）、PWM（舵机）。
- **控制算法**：FOC（有感+无感）、步态逆运动学（IK）、串级 PID、sim2real 强化学习方向。
- **调试工具**：VOFA+（波形上位机）、RMD config / RMD V2.0.exe、sscom（RS485）、esc-configurator.com（在线 ESC 烧录）、示波器。

### 2.2 通信协议要点

#### CAN

- 调试仪：**达妙双路 CAN 调试仪**（资料在 https://gitee.com/kit-miao/dm-tools/tree/master ，朱佩韦：「资料全的，有问题去提 issue」[2025-12-27]）。
- 第三方：**PCAN USB-TO-CAN**（客户资料：https://pan.baidu.com/s/1MIIFShnwwEhHzhNxv1K7GA?pwd=1234 提取码 1234）。
- CubeMars 电机驱动板配套资料：《多路独立 CAN 总线+多路 TTL 串口或 485 总线控制板资料.rar》。
- STM32 侧例程：F407_can.rar。

#### RS485

- 宇树电机走 485，但**宇树的 485 转 USB 模块不能直连电脑调试 RMD/CAN 电机**，需要再用 485 转 CAN 模块转接，或者直接用达妙的 USB 转 CAN（朱佩韦：「用达妙的这个是顶配」[2025-12-27]）。
- RMD 电机排查 485 信号：先用 **RMD config** 原生串口进去看固件（[2025-12-25]）。

#### PWM / 舵机

- 实测：PWM 信号线 3.6V，VCC 4.9V（魏卫 [2026-03-09]）。
- **万用表直流档测 PWM 电压不规范，要看波形用示波器**（魏卫自检 + 朱佩韦建议 [2026-03-09]）。
- 舵机「有效识别窗口」：信号脉宽超出窗口会导致识别不到，现象是「接上一个口能转、换个口不转」或「插上还影响别的舵机」（田旺旺、魏卫 [2026-03-12 / 03-13]）。

#### SBUS

- 大疆 A 板做 SBUS 接收，「交大的工程上面开源了这个的控制」可抄（[2026-01-08]）。

### 2.3 电源与配电

- **3508 与 6020 电机供电不同**：3508 单块电源不够，110W 最高负载，BC50 电池要 **两块并联**（朱佩韦 [2025-12-01]）。
- 电池组自制：18650 + 点焊机 + 镍带 + 青稞绝缘纸（[2025-12-01]）。
- 舵狗调试期电源：**优先用可调稳压电源**，电池供电容易触发过流保护或舵机掉电重启（刘成龙、朱佩韦 [2026-03-16]）。绿板电源模块故障现象：插舵机一直掉电重启 → 换蓝板、改稳压电源排查。

### 2.4 调试方法论

1. **上电前**：先确认原理图引脚对应、三根线（信号/VCC/GND）顺序、ESP 端口号；「别接反了」（朱佩韦 [2026-03-09]）。
2. **库一律用现成**：「调库别自己写」「Trae 写手搓库很不稳」（朱佩韦 [2026-03-09]）。
3. **分层排查**：上电亮但不动 → 查端口/引脚 → 用逻辑分析/示波器看 IO 输出 → 换一块确实能用的舵机/电机交叉验证。
4. **电机交叉测试**：怀疑舵机坏时，把它插到另一个能转的口上复现（刘成龙：「交叉个舵机看看」「或者示波器看一下波形」[2026-03-18]）。
5. **拍视频留证**：所有调试里程碑拍视频发群里（赞助方要求、指导老师验收都要）。

## 5. 常见问题与经验教训

### 5.1 硬件坑

- **舵机玄学坏**：魏卫案例——舵机不通电放一晚自己坏掉，事前无征兆。对策：每次调试结束拍视频留证，坏件拆下来寄回厂家（寄送地址语料中给了两个：广东深圳福田振兴路 156 号上步工业区 405 栋 416 室、江苏常州武进永安花苑 107 甲 1702）。[2026-03-18]
- **舵机臂型号**：**25T 和 20T 都不能用**，必须用 **18T、直径 4.3 mm**（[2026-04-16]）。
- **接上坏舵机会拉垮整条总线**：魏卫实测「不仅自己不能转，插上还会影响别的舵机转动」，排查时先单独断电拔掉可疑件（[2026-03-13]）。
- **绿板电源模块故障**：插舵机一直掉电重启 → 换蓝板、用稳压电源先排除供电变量（[2026-03-16]）。
- **CAN 转接**：宇树 485 转 USB 模块 ≠ CAN 分析仪，调 CubeMars/RMD 必须用达妙 USB 转 CAN 或 PCAN（[2025-12-27]）。

### 5.2 软件/方法坑

- **不要手搓库**：朱佩韦反复强调「调库别自己写」「Trae 写手搓库很不稳」，框架自带的库先用熟（[2026-03-09]）。
- **PlatformIO ≠ ESP-IDF**：田旺旺混淆「嘉立创上面信息是 idf」，实际上 IDF 是编译/包管理器，看不熟芯片手册时不友好，新人优先 PlatformIO / Arduino 框架（[2026-03-09]）。
- **万用表测 PWM 不规范**：要看波形用示波器或逻辑分析仪（[2026-03-09]）。
- **链接会失效**：闲鱼链接、百度网盘链接常坏，群里定期核查并更新（朱佩韦 [2025-11-22]；单广志「坏了，链接失效了」[2025-12-27]）。

### 5.3 流程坑

- **赞助电机有时效**：麦塔 5015 12 个、CubeMars AK10-9 都要求 **2 周内测完并发测试视频**，否则合作协议签不下来（[2025-11-02 / 11-13]）。
- **里程碑会延**：舵狗原计划 3.20 完成基础功能，实际 4.4 才把前进/后退/左右转做完，被刘成龙催「一个月才做了四分之一的功能」——**预留 1.5–2 倍缓冲**（[2026-03-30]）。
- **群文件命名混乱**：NEC-Claw 给出三条建议——强制前缀分类（【资料】/【图纸】/【代码】/【会议】）、按月归档到云盘、群里只留当前版本（[2026-03-09]）。

## 6. 新人上手路径建议

按语料中实际踩过的顺序整理：

1. **第 1 周｜环境搭建**
   - 装好 PlatformIO IDE（参考《PlatformIO IDE 下载及环境配置教程》）。
   - 装好 VOFA+、sscom、RMD config。
   - 加飞书：电控总群、舵狗群、项目管理 Base、达妙资料飞书免登录盘。
2. **第 2 周｜跑通第一个电机**
   - 从 **M3508 + 南邮 70 电调** 或 **达妙 DM-MC02 + 8010** 入手（语料里跑通最多的两套）。
   - 用现成例程：F407_can.rar 或达妙 Gitee 仓代码。
   - 拍视频发群，确认接线、上电、转动全流程。
3. **第 3–4 周｜读框架、做调试**
