## 1. 工种概述

### 1.1 职责定位
机构/机械组（下称"机构组"）在 NEC 内的核心职责：

- **结构设计**：机器人本体、底盘、升降、抓取、传动等机械方案设计与出图（SolidWorks 为主）。
- **图纸评审与冻结**：参与每周机械图纸评审会，按里程碑推进"设计中 → 图纸冻结 → 采购中 → 机加排队 → 装配中 → 调试中 → 已完成"。[机构群 2026-02]
- **BOM 编制与采购对接**：出 BOM Excel，配合淘宝/嘉立创/闲鱼比价，向采购/财务同学交付下单依据。
- **加工与装配**：校内 3D 打印（PETG/TPU）、激光切割（玻纤板 3mm 内、500×500mm 行程）、CNC 雕刻机、外发机加（诚品金科、振心等）、焊接与回流焊。
- **跨组协同**：与电控（电机/电调/驱动板）、视觉（摄像头安装位）、运营（招商赞助）强耦合。

## 2. 核心知识体系

### 2.1 设计原则（团队共识）

1. **"设计不要太高，满足需要的机构就可以"**——预算与功能平衡，先简单实现再迭代。[机构1组 2026-01]
2. **从咸鱼/淘宝搜现成件反向设计**："先找图片，从咸鱼上找你要的型号；要不然画出来没法加工。"[机构1组 2026-01]
3. **模块化 + 标准件复用**：优先使用 2020 国标方管（**黑色阳极氧化/光面**，**不要白色带漆皮**，影响打孔精度）、3030 欧标（黑色哑光）方管+连接板+螺栓的核心结构逻辑。[机构群 2026-01/05]
4. **打印件受力分级**：受力件 **80% 以上填充**；非受力件 **15% 填充**并要求**打标标注**。[机构群 2026-05]
5. **快速验证优先**："PETG 实心验证" → 验证通过后再外发机加，缩短迭代周期。[机构群 2026-03]
6. **图纸必须能加工**："没有钻孔和装配条件，建议直接外发"。参考武大/华南理工的方管设计（**大定位过孔+小连接孔**）。[机构群 2026-05]
7. **轻量化**：方管"国标 1mm 以及顶多 3mm"，不要过度堆料。[机构群 2026-03]

### 2.2 底盘/移动机构

**常见方案对比（语料中真实出现）：**

| 方案 | 代表机型 | 备注 |
|---|---|---|
| 麦克纳姆轮 | R2（中心偏高） | 全向移动但重心偏高 |
| 全向轮（Omini） | R1、排球 | 低矮、重心低，配合 M3508+N630 |
| 舵轮 | T30 / U8 方案 | 动力+转向合一，适合高机动 |
| 狗腿+舵轮 | 爬坡方案 | 2025 赛季爬坡讨论 |
| 麦克纳姆 vs 全向 | R1/R2 混合 | 底盘方案 5/10 调整过：R1 原底盘给 R5，R1 改方管底盘 |

**舵轮（T30/U8）关键讨论**：
- T30 是大疆 T30 **植保无人机拆机电机**，**峰值功率 3600W，最大电流 60A，额定电压 51.4V**（不是 24V，注意歧义）。曾出现文档把 T30 写成"舵轮专用电机 240W"的乌龙，后修正。[机构6组 2026-03]
- U8 与 T30 建模与孔位适配工作并行。T30-motor 出 stp/stl/3dm 三种格式。[机构3组 2026-02]
- U8 舵轮扭矩不足是反复出现的问题："之前我们改过一版 5015 的，应该扭矩不够，原版设计是 6020"[机构群 2026-10]
- 舵轮方案 2026-05 由邵仁昱提交 v1/v2 两版。[机构群 2026-05]

### 2.3 升降/直线运动

- **直线导轨方案**：DM3519 + DM-MC02 联调（机构2组），已完成驱动验证。
- **同步带升降（R1 主推方案）**：M3508 减速电机 + 同步轮。参数实测参考：
  - M3508 减速后额定扭矩约 **2.4 N·m**；53.9mm 同步轮半径 27mm → 直线推力约 **90N（≈9kgf）**。
  - 同步带**张紧度**：手指压皮带，单侧下沉量控制在 **5-8mm**；过松跳齿，过紧轴承过载。
  - 跳齿/异响处理：先调张紧、再调加减速曲线；断电自锁可上电机刹车模式或顶部气弹簧/拉簧。
  - 滑车 vs 双滑块：ZYGG（南航）推荐**单滑轨双滑块**，已实际改滑车；平行双滑块精度不足。[机构群 2026-06]
- **丝杆/导轨**：滑块拼接技巧——"先把滑块停到接缝处，然后松开其中一根导轨的螺丝，然后再拧紧"。[机构群 2026-03]

### 2.4 抓取/末端执行器

- **气动夹爪**（机构1组）：旋转气缸（90°） + 气动夹爪，目标抓取 14mm PVC 圆管；预算 100 元以内，闲鱼采购；末端接触用**软性 TPU 打印件**，结构件用 PETG 打印。[机构1组 2026-01]
- **吸盘**：排球/R2 末端用，配气泵（卡默尔 KVP04 微型真空泵 12V 隔膜泵）。[机构群 2026-07]
- **步进电机夹爪**：单广志验证过可行性。[机构群 2026-01]
- **气缸选型**：SMC 官方选型软件 https://smss.smcworld.com/cdsss/index.php [机构群 2026-05]

### 2.5 全向轮/麦克纳姆轮

- 开源方案 **OpenTpuOmniWheel**（GitHub：Dadingdang/OpenTpuOmniWheel，Gitee 同步镜像 darrenpig/OpenTpuOmniWheel）：
  - 轮子材料两种：**聚氨酯 5.5 元/个，橡胶 9 元/个**（含轴承销钉垫片），硬度 50A。
  - "请平等对待每一个 RMer"——开源作者留言。
- 全向轮联轴器曾被误用于非预期用途（"薅过去玩 520 螺丝"），团队资源使用需注意。[机构群 2026-05]

### 2.6 编码轮/里程计

- 正交码盘场地定位系统：https://oshwhub.com/roboticlib/yi-yan-zheng-zheng-jiao-ma-pan-chang-di-ding-wei-xi-tong
- 编码轮 3D 打印版已在群文件，2026-07 由崇瑶完成编码器 PETG 打印件（约 3h29m）。
- 2026-07 朱佩韦明确："目前我们缺里程计定位方案"，是赛季遗留痛点。

### 2.7 电池/供电配套（机构需知）

- **插头标准**：XT30 为团队集中供电主流（24V 系统）；XT60/XT90 也存在但较少；**注意 XT30U 与 XT30 尺寸略有差异**（淘宝商家确认一致，但实际使用要再问清楚）。[机构群 2026-03]
- **N630 电调电流承载**：拉 10A 可持续 10 分钟，拉到 15A 只能撑几十秒。N630 支持 4-12S 电压。
- **配线**：电机线径（AWG）按通过电流计算；M3508 线电流承载约 15A（待手册核实）。
- **功率冗余**：总功率按峰值累加，再留 **10% 冗余**。[机构群 2026-03]
- **M3508 与 GM6020 供电不同**，注意区分。
- **3508 电源不够时需两块电池并联**。

## 3. 标准流程与协作规范

### 3.1 设计→交付流程

```
方案讨论（组内/评审会）
  → SolidWorks 建模 → 导出 STEP/STL/DXF
  → 图纸评审（周会，飞书视频会议 + 评审意见表单）
  → 图纸冻结 → BOM 出表
  → 比价（淘宝 + JLC + 华秋 + 闲鱼，至少 3 家）
  → 加工下单（校内 3D 打印 / 激光 / 雕刻机 / 外发）
  → 装配 → 调试 → 评审复盘
```

参考节点（2026 赛季实际执行）：2/20 机械方案评审 → 3/15 机械冻结 → 4/1 代码冻结 → 4/15 联调 → 3/31 中期检测 → 7/5 正式赛（ROBOCON 2026）。

### 3.2 图纸评审流程

- 例会：27 机械图纸评审会（飞书视频），评审意见收集通过飞书表单在线填写，**评审人+总体结论为必填**。[27机械图纸评审 2026-09]
- 评审后输出图纸审批单号（如 MECH-2026-0001 / DR-20261014-T04），走中台审批流，超期会告警（>48h 未排会 / >72h 未整改）。[机构群 2026-10]
- 图纸导出格式：**机械装配统一出 STEP/STP**（便于 SolidWorks、Rhino、UG 通用），**打印件出 STL/3MF**，**激光/雕刻下料出 DXF**。

### 3.3 BOM 编制与采购流程

**BOM 标准动作：**
1. BOM Excel 必须含：名称、型号、规格、数量、单价、总价、店铺链接、备注（参考 `N630电调_BOM.xlsx`、`R2 BOM.xlsx`、`N630+3508_采购清单.xlsx`）。
2. **无报价的统一整理标红**。[机构群 2026-03]
3. **至少 3 家比价**，外发加工件尤其。
4. 元器件**避免多店铺分散采购**（运费会超过材料费）——"PCB 我们要 30 份 BOM，单采价格不准，里面运费比材料贵。"[机构6组 2026-02]
5. 配单商家报价通常比自购高 1.5 倍（行业标准），能自己配就自己配。

**采购渠道优先级（语料实践）：**
- 元器件/PCB：嘉立创 JLC（SMT、PCB 打样，可领券）、华秋（SMT 优惠券）、立创开源广场。
- 通用件：淘宝（注意要求店铺截图 + 大体示意）。
- 二手/拆机件：闲鱼（**只买"全新学生优惠"或可靠来源**；"拆机的不敢买"[NEC-机械 2025-11]）。
- 方管加工：**诚品金科、振心**（团队推荐）。[机构群 2026-05]
- 急件小件：校内 3D 打印 / 激光切割 / 雕刻机。

### 3.4 加工流程

**校内可加工能力：**
- 3D 打印：PETG（默认首选）、TPU（直接塞挤出机，**不要走料管**）、PLA（不推荐，强度不如 PETG）。[机构群 2026-04]
- 激光切割：**玻纤板 3mm 内、500×500mm 行程**（**剧毒烟气：甲醛+溴化氢+二噁英，必须独立抽风+防毒面具**）。[机构群 2026-03]
- CNC 雕刻机：加工木材、电木板；**水泵必须先打开**，避免干烧；**刀头建议先拆下来练习**，避免撞刀。[机构群 2026-05]
- 焊接：回流焊台 + 激光钢板 + 刷锡浆（N630 工艺升级方案）。
- 点焊：电池组定制（18650+点焊机+镍带+青稞绝缘纸）。

**外发条件：**
- 量超 500×500mm、厚度 >3mm、批量 >10 件、有沉头/螺纹孔需求 → 外发。
- 急件/打样 → 校内优先，"验证件/打样用自加工，最终量产件外发"。

**禁止事项：**
- **416 实验室门口和外面禁止使用雕刻机**（粉尘噪音）。[机构群 2026-06]
- 严禁在实验室留宿、做饭、堆被褥锅具。[机构群 2026-10 黄奕老师要求]

### 3.5 装配与调试

- **装配顺序**：底盘 → 动力 → 升降 → 末端 → 电控布线 → 视觉标定。
- **每周日晚 8 点机构组周工作汇报**（NEC Claw 自动生成，从 Base 拉取）。
- **进度更新要求**：每 2 周必须有 1 次提交/进度更新，超 2 周自动标记风险，超 3 周升级总群。[机构群 2026-02]
- **Base 状态字段**：设计中 / 图纸冻结 / 采购中 / 机加排队 / 装配中 / 调试中 / 已完成（**不要使用** 待开始/进行中/已完成 这种粗粒度）。[机构群 2026-02]

## 5. 常见问题与经验教训

### 5.1 加工/装配踩坑

1. **M2.5 内六角螺丝滑牙**：底孔应为 2.2mm；滑牙后推荐钢丝螺套（Helicoil，可升级 M3）；3D 打印件螺纹需预留补偿；避免反复拆装；顶部加 45° 倒角。[机构群 2026-03]
2. **m3\*30 螺丝实际全是 m3\*27**：紧固件验收要逐项核对。[机构群 2026-05]
3. **开发板反面导电**："下面是金属导体，上电会炸的……开发板记得做绝缘隔离"。[机构群 2026-04]
4. **N630 烧录口 3V3 和 GND 短路冒火花**：焊接时别乱碰烧录口。
5. **N630 烧录不进**：注意看烧录手册，可能需要换电池。
6. **同步带跳齿**：张紧度不够、负载突变、加减速过陡都会引发；用手指压 5-8mm 下沉量判断。
7. **升降机构下降异响**：可能是板件绷直或皮带滑齿；下降采用电机失能+重力方案时注意 P 值调小。[机构群 2026-06]
8. **舵轮 U8 扭矩不足**：原版 6020 改 5015 后扭矩不够，方案评审时被反复打回。**教训：电机替换前必须算扭矩。**
9. **博世工具生锈**：备 WD40，建立工具保养清单。[机构群 2026-05]
10. **打印件受力不足**："受力件 80% 填充，非受力件 15% 填充"，必须打标。[机构群 2026-05]
11. **3D 打印 PLA vs PETG**：PLA 强度不如 PETG，团队默认 PETG；TPU 直接塞挤出机不走料管。
12. **打印热床 / 料盘**："不要无热床打印。打印开始前检查热床、耗材"。料盘上胶用喷雾型不用液体胶。
13. **K1C 热床干穿**：维修教程需提前储备（创想官方 wiki）。[机构群 2026-05]
14. **激光切割玻纤板**：剧毒烟气（甲醛+溴化氢+二噁英），必须独立抽风 + 防毒面具（3M 7502+6001 滤毒盒），不能用普通口罩；加工后湿式清洁，禁止干扫。[机构群 2026-03]
15. **雕刻机水泵**：必须先开，避免干烧；新刀头先拆下练习避免撞刀。
16. **416 门口禁用雕刻机**：粉尘噪音污染。[机构群 2026-06]
17. **实验室严禁留宿做饭**：黄奕老师 2026-10 新规。

### 5.2 选型/采购踩坑

1. **全新 vs 拆机**："拆机的不敢买"，宇树 8010 学生优惠 497 元最靠谱；二手风险高。
2. **电机功率文档错标**：NEC Claw 曾把 T30 写成 240W（实际是大疆 T30 植保机 3600W）。**手册数据要核实，不能盲信二手整理。**
3. **峰值功率虚标**：李嘉涵算功率时发现"手册上没标出来，我就 AI 了"——**禁止让 AI 估算参数，必须查官方手册**。[机构群 2026-03]
4. **Go2 Air 电机 ≠ 8010**：宇树 Go2 Air 是专用电机，参数和控制都得调。[NEC-机械 2025-11]
5. **N630 BOM 报价差**：JLC ¥92.61/片 vs 自配 ¥48.41/套，**自配便宜近一半**；配单商家通常贵 1.5 倍。
6. **闲鱼链接失效**：注意及时更新机械群内的采购链接。[NEC-机械 2025-11]
7. **店铺少买 vs 多店分散**：运费会超过材料费，元器件尽量集中。
8. **齿轮箱外发被驳回**：DR-20261014-T10 因齿形参数需复核+材料建议改 40Cr 被卢王淳驳回——**评审要看材料和工艺，不是只看结构**。

### 5.3 流程/协作踩坑

1. **Base 任务状态滞后**：2026 赛季 2-3 月录入，后续 6 个月没更新，导致后期无法追踪。**每周必须更新，进度巡检机器人会查。**
2. **派工不明 = 0 进度**：PCB 下单当天执行 0%，根因"没定到具体人、没定几点前要结果"。**派工必须明确负责人 + 截止时间。**[机构群 2026-10]
3. **文件命名混乱**："2.nc"、"2 (2).STEP"、"电机座323232.dxf"——**必须建立统一命名规范**。
4. **链接失效**：飞书/百度网盘链接会过期，重要资料多点备份（Gitee + 飞书 + 群文件）。
5. **"机构 3/4/5 组连续三周零汇报"**：组长失联会拖慢整个团队，**定期例会必须有产出**。
6. **舵狗调试严重超期**：原定 3/20 完成，4/5 仍在调，超 15 天。**里程碑要留 buffer。**
7. **中期检测逾期 40+ 天**：3/31 节点拖到 5 月仍未闭环，赛季后期被严重压缩。
8. **机密信息保护**：飞书 Base 授权别外发；VOFA+ 授权码、校园网账号等不要在群里贴。[机构群 2025-12]
9. **数码宝贝代号歧义**："阴阳电机"=名扬电机、"MC500"=MC50 轮趣——**型号要写规范**。[机构群 2026-03]

### 5.4 电控衔接（机构需了解）

1. **N630 vs C620**：N630 便宜一半，参数需自调；电流承载能力较弱（10A/10min、15A/几十秒）。
2. **DM-MC02 三坑**：USB-C 不能烧录；CAN H/L 反相；调试器供电不足需 USB 直供。[机构6组 2026-04]
3. **宇树 8010 接线**：USB 转 RS485 时 CAN/RS485 端子短接，红黑线调换。[机构2组 2026-01]
4. **3508 电调可用 N630 或 C620**，两者 CAN 协议兼容，但 PID 需重新调。
5. **AK70 vs AK90**：AK70 扭矩小不能上狗赛，AK90 才能替代 DM8009。
6. **RMD 485 通信问题**：用 RMD Config 原生串口工具看固件。
7. **Falcon2 激光气泵**：自检后气泵自动停，工作开始才启动；进气检测灯红≠故障。

## 6. 新人上手路径建议

### 6.1 第一周（基础认知）

1. 读完本手册 + [NEC 新人 60 分钟 Quickstart](https://scn0bdoc8zxg.feishu.cn/wiki/QAtNwr244ir8ZekITEZcwpOZnkg)。
2. 装 SolidWorks（含 GearTrax、麦迪工具箱），跟着画一个简单零件（推荐：M3508 电机座、2020 方管连接板）。
3. 跑一次 3D 打印：K1C 打印机使用说明书（飞书 Wiki），打印一个练习件（PETG，受力件 80% 填充）。
4. 加入 Gitee/GitHub 组织 necc-hub，完成仓库培训。
5. 认领一个 1-2 天能完成的小任务（如主控三视图导出、简单打印件）。

### 6.2 第二周（专业深化）

1. 选定方向：
   - **结构设计**：跟机构1组（毕卫亭）学气动夹爪 / 机构5组（黄宇雯）学升降；
   - **底盘/舵轮**：跟机构3组学 T30/U8；
   - **驱动板**：跟机构6组学 M3508+N630；
   - **学习沉淀**：机构12组（SolidWorks 基础学习组）。
2. 看中科大 RM 进阶课电机控制章节。
3. 看 ZYGG 机械课（直线和回转设计方法，QQ 群 384112558）。
4. 阅读至少一份往届开源方案：重庆邮电大学机械库 / 西南交大 RM2022 步兵 / 24UESTC R1R2。

### 6.3 第三周起（实战上手）

1. 在机构组 Base 中认领 Story 级任务，按"设计中→图纸冻结→采购中→机加排队→装配中→调试中→已完成"推进。
2. 每周日晚 8 点前更新 Base 状态（**强制**）。
3. 出第一版图纸 → 提评审 → 根据反馈迭代 → 出 BOM → 跟进采购加工装配。
4. 常见踩坑前先翻第 5 章"常见问题"。

### 6.4 软技能

- **会提问**：先查群文件/知识库/往届开源，再问；提问带截图带型号带已尝试方案。
- **会汇报**：进度阻塞超过 24h 主动说，不要等周会被点名。
- **会沉淀**：调试记录、踩坑笔记发群里，NEC Claw 会归档。
- **会协作**：跨组问题（机械×电控×视觉）主动拉会，不要文字拉锯。
