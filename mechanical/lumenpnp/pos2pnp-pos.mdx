# 软件概述

pos2PnP 是专为 OpenPnP 设计的专业 POS 文件转换工具。它能将各种 EDA 软件的 POS 文件格式转换为 OpenPnP 兼容的标准 CSV 格式。

## 主要功能

统一标准化的元件和封装命名，方便OpenPnP自动匹配并自带封装高度，无需手工输入。

自定义坐标旋转，方便按用户角度放置pcb。



📁 多格式支持

KiCad POS 文件 (.pos)

Altium Designer 贴片文件 (.txt, .csv)

Eagle 安装文件 (.mnt)

EasyEDA/JLCPCB 文件 (.csv)

通用 CSV/TXT 格式





🔄 智能转换

自动文件类型检测

编码自动识别（UTF-8, GBK, GB2312 等）

智能封装名称映射

元件高度数据集成

坐标系统标准化



🎯 电路板旋转支持

支持 0°、90°、180°、270° 旋转

逆时针旋转变换

自动坐标重新计算



📦 封装库

1000+ 封装映射

标准化封装高度数据库

易于扩展和自定义



# 使用教程

在 OpenPnP 中，进入 File → Import → Reference CSV

选择转换后的 CSV 文件

启用以下选项：

✅ Create Missing Parts（创建缺失的元件）

✅ Update Existing Part Heights（更新现有元件高度）



点击 Import
