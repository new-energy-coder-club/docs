<title>更新飞达固件</title>

所有送料器均预装固件。以下说明适用于更新新版固件或将自定义固件安装到送料器。

1. **将下载器跳线设置为 3.3v**

确保编程器上的3 针接口跳线设置为 3.3V。确保跳线将中间的针脚连接到标有“3.3V”的针脚。飞达主板芯片的逻辑电平工作在 3.3V，因此在使用前应将其设置为 3.3V。

<callout emoji="❗">
**非常重要**
下载器默认是5V，请一定按下图调整跳线位置，否则飞达主板可能损坏。
</callout>

# 编译Feeder源码（面向开发人员）

LumenPnP 送料器运行[Photon](https://github.com/photonfirmware/photon)固件程序，这是一个用于拾取放置送料器的开源固件项目。OpenPnP内置了对 Photon 的支持，因此您可以轻松地将 LumenPnP 送料器与现有的 OpenPnP 设置配合使用。这些送料器专为与[LumenPnP](https://opulo.io/products/lumenpnp)配合使用而设计。

默认`pio`环境旨在与[Black Magic Probe](https://black-magic.org/index.html)配合使用，用于上传调试信息：

```Plain Text
pio run
```

但是，如果您只想通过 UART 对飞达进行编程，例如使用 LumenPnP 附带的 FTDI USB UART 桥接器，则可以使用：

```Plain Text
pio run -e photon-serial -t upload --upload-port /dev/tty...
```
