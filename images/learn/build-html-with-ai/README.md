# 截图拍摄指南（build-html-with-ai 教程）

本目录用于存放教程 `start-here/build-html-with-ai.mdx` 所需的全部截图。

## 拍摄环境要求

- **操作系统**：Windows 11（21H2 及以上，建议全新安装或重置过的环境，避免私人文件入镜）
- **分辨率**：1920×1080，缩放到 100%（不要用 125%/150%）
- **浏览器**：Microsoft Edge（Win11 自带）或 Chrome
- **AI 工具**：TRAE 最新版（https://www.trae.ai）
- **截图工具**：Win11 自带「截图工具」（Win + Shift + S），保存为 PNG

## 通用拍摄规范

1. **关闭无关窗口**：只保留教程相关的 1 个窗口，桌面不要出现个人文件、微信/QQ 弹窗
2. **隐去个人信息**：任务栏右下角时间、用户名等如有隐私顾虑可后期打码
3. **窗口最大化**：除特别说明外，所有截图都是被拍窗口最大化的全屏截图
4. **关键操作高亮**：用 Win11 截图工具的「红框」或「箭头」标注按钮位置（教程文字中提到的"红框"指的就是这个标注）
5. **统一命名**：按下表文件名命名，PNG 格式

## 拍摄顺序建议

按教程章节顺序拍（00 → 10），因为后续步骤依赖前面的状态（例如 09 依赖 06 保存好的文件）。

## 后期处理

- 用 [ShareX](https://getsharex.com/) 或 Win11 截图工具加箭头/红框
- 单张图不超过 500 KB（必要时用 [Squoosh](https://squoosh.app/) 压缩）
- 不要加水印

## 替换占位符

拍好后直接放入本目录，文件名与上表一致即可，无需修改 mdx 文件（占位符路径已对上）。
